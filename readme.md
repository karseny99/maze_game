## Описание игры
Сгенерированный лабиринта, в котором, чтобы выйти необходимо нажать на несколько кнопок в разных его частях одновременно. Для этого игрок должен в начале найти эти кнопки, записать путь к ним, и запустить своих клонов по этим записанным путям. Затем игроку необходимо синхронизироваться со своими клонами и нажать на кнопки одновременно, сделать это можно, ориентируясь на picture-in-picture режим просмотра их действий.

---

## Механики
* Запись маршрута: необходимо выбрать клона в UI панели, затем нажать кнопку F, чтобы начать и завершить запись.
* Автоматический возврат игрока на стартовую позицию при начале новой записи для синхронизации таймингов.
* С началом записи выводится picture-in-picture вывод действий клона для синхронизации нажатия кнопок. 
* При нажатии кнопки R все призраки запускаются по записанным маршрутам.
* Нажатие всех кнопок одновременно триггерит открытие портала-выхода.

## Технические особенности
* Использовано запекание света в сцене.
* Использован сторонний unity [пакет](https://github.com/CristianQiu/Unity-URP-Volumetric-Light) для создания объемного света в плотном тумане. 
* Для визуализации портала использован VFX Graph.
* Реализован алгоритм генерации лабиринта заданных размеров с разной степенью освещенности внутри и разным количеством кнопок. 
* Текстуры для лабиринта и модельки для призраков взяты из магазина unity. 

## Управление
* `WASD` - передвижение.
* `F` - начать/остановить запись.
* `R` - запустить всех записанных клонов.
* Для выбора клона для записи необходимо нажать `ESC` и выбрать соответствующий слот в UI панели.
